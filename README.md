# Cloud Security Monitoring & Threat Detection Lab

This project demonstrates the implementation of a cloud security monitoring environment designed to identify suspicious activity, investigate security events, and automate alerting for potential threats.

## Objectives

* Monitor cloud activity for malicious behavior
* Detect unauthorized access attempts
* Identify privilege escalation activity
* Generate automated alerts
* Build incident response workflows

## Technologies Used

* AWS CloudTrail
* AWS GuardDuty
* AWS Security Hub
* AWS CloudWatch
* EventBridge
* Lambda
* SNS

## Simulated Threat Scenarios

* Unauthorized console access
* Suspicious API activity
* Excessive IAM permission usage
* Public resource exposure
* Privilege escalation attempts

## Key Features

* Centralized security monitoring
* Automated threat detection
* Event-driven alerting
* Security dashboard reporting
* Incident response playbooks

## Business Value

Demonstrates cloud security operations, threat detection engineering, and security monitoring practices commonly used by cloud security and DevSecOps teams.
